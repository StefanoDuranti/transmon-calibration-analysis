# transmon-calibration-analysis
Exploratory analysis of public calibration data from IBM Quantum superconducting processors

## Data

The data consists of calibration snapshots of IBM Heron processors, collected by Charles C. Norton and published on Hugging Face as [phanerozoic/qiskit-calibration-drift](https://huggingface.co/datasets/phanerozoic/qiskit-calibration-drift) (CC-BY-4.0). This repo does not redistribute data, but rather download a local version which is excluded from the repo itself.
